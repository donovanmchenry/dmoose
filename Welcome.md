# Welcome to Dmoose

Open this folder in Codex or another file-aware assistant and say: **“Set up this
second brain with me.”** The assistant will follow the [guided onboarding](ONBOARDING.md)
and ask questions before creating personal files. No developer tools are required.

After onboarding, open the [Dashboard](Dashboard.md).

Use the local [User Profile](USER.md) for confirmed personal context, the local
[Now Page](NOW.md) for current priorities, the [Project Registry](projects/index.md)
for project discovery, and the [Wiki Index](wiki/index.md) for durable knowledge.
