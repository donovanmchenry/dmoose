# Projects

This folder is a discovery layer, not a container for other repositories.

- `index.md` is the tracked project registry.
- `<project-id>.md` is a tracked, non-sensitive project profile.
- `project-template.md` is the reusable profile template.
- `local-paths.md` maps external projects to this machine and is gitignored.
- `local-paths.example.md` is the safe path-map template.

Project source stays in its own repository. Profiles point to authoritative files and
record durable context without copying credentials, customer data, or private source
material into Dmoose.
